# Pulse Build 0.2.0

## Purpose

First usable deterministic KPI vertical slice.

## Added

- Category Sales Share
- independent current and comparison dataset selection
- independent current and comparison channel selection
- `All channels`
- non-blocking comparison-scope warnings
- company category overview
- selected-category restaurant breakdown
- Explain section
- Reports linked to the same selected result

## Corrected architecture

Category Sales Share is channel-neutral.

2025 is not a permanent baseline. Any trusted dataset may be selected as the comparison reference.

## Not included

- Category Quantity Share
- Add-ons Attach Rate
- Estimated NOK Impact
- Trend
- Leaderboard
- Labour
- Reviews
- AI recommendations

These remain future work.

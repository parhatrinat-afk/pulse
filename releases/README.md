# releases

This directory contains release/checkpoint documentation and packaged artifacts where appropriate.

Current release/checkpoint folders include:

- `0.2.0/` — Build 0.2.0 release material.
- `0.2.0-QA/` — QA checkpoint material used as the validated starting point for Build 0.3.0.

A planned or in-development build should not be presented here as validated until there is a concrete artifact plus QA evidence. Build 0.3.0 remains in development until those conditions are met.

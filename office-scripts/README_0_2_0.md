# Office Scripts

## Build 0.2.0

`Build_0_2_0.ts` is the first repository-owned workbook build script.

It is intended to be run once against the current Build 0.1.1 checkpoint in Excel for the web.

After validation, save the resulting workbook as `excel/Pulse_Build_0_2_0.xlsx`.

The script is source-controlled. The generated workbook is the release artifact.
